¿Qué es MITRE ATT&CK?

MITRE ATT&CK (Adversarial Tactics, Techniques and Common Knowledge) es una base de conocimiento pública y gratuita que documenta el comportamiento real de atacantes cibernéticos. Fue creada por MITRE Corporation en 2013 y hoy es el estándar global para describir cómo los adversarios comprometen sistemas.

La idea central es simple pero poderosa: en lugar de catalogar malware o firmas técnicas (que cambian constantemente), ATT&CK cataloga el comportamiento del atacante — qué hace y cómo lo hace.

Pensalo como un "manual del atacante" documentado. Si un grupo APT como Lazarus Group quiere robar credenciales bancarias, los pasos que va a seguir son predecibles y están documentados en ATT&CK. Eso nos permite detectarlos antes de que lleguen al objetivo final.

Las 14 tácticas: el ciclo de vida del ataque

ATT&CK organiza el ataque en tácticas — cada una representa el objetivo que el atacante quiere lograr en esa fase. Debajo de cada táctica hay técnicas (el cómo) y sub-técnicas (variantes específicas).

TA0043
Reconocimiento
El atacante recolecta información sobre el objetivo antes de atacar: correos, IPs, tecnologías usadas.
Ejemplo real
Scan de puertos con Shodan · OSINT en LinkedIn
TA0042
Desarrollo de recursos
Preparación de infraestructura: registrar dominios falsos, crear cuentas, compilar malware.
Ejemplo real
Dominio typosquatting · C2 en bulletproof hosting
TA0001
Acceso inicial
El primer punto de entrada al sistema objetivo. La puerta de entrada al ataque.
Ejemplo real
Phishing con adjunto malicioso · VPN sin parchear
TA0002
Ejecución
El atacante logra correr código malicioso en el sistema de la víctima.
Ejemplo real
Macro de Office · PowerShell · RCE (Remote Code Execution)
TA0003
Persistencia
El atacante asegura su acceso para no perderlo si el sistema se reinicia o cambia.
Ejemplo real
Backdoor en el registro · Tarea programada maliciosa
TA0004
Escalada de privilegios
Pasar de usuario normal a administrador o SYSTEM para tener control total.
Ejemplo real
Exploit de kernel · DLL hijacking · UAC bypass
TA0005
Evasión de defensas
El atacante intenta pasar desapercibido: desactivar antivirus, borrar logs, ofuscar código.
Ejemplo real
Living-off-the-land · Timestomping · AMSI bypass
TA0006
Acceso a credenciales
Robo de contraseñas, hashes, tokens o certificados para moverse lateralmente.
Ejemplo real
Mimikatz · Credential dumping · Keylogger
TA0007
Descubrimiento
Mapeo interno de la red: qué sistemas existen, qué usuarios, qué servicios corren.
Ejemplo real
Net discovery · BloodHound en Active Directory
TA0008
Movimiento lateral
Expansión a otros sistemas dentro de la red usando credenciales o exploits internos.
Ejemplo real
Pass-the-Hash · RDP · SMB exploitation
TA0009
Recolección
Acceso y captura de los datos objetivo: archivos, emails, bases de datos, capturas de pantalla.
Ejemplo real
Exfiltración de emails · Screen capture · Keylogging
TA0011
C2 / Comando y Control
Canal de comunicación entre el malware en la víctima y el atacante para recibir órdenes.
Ejemplo real
Cobalt Strike · DNS tunneling · C2 sobre HTTPS
TA0010
Exfiltración
Transferencia de los datos robados fuera de la red de la víctima hacia el atacante.
Ejemplo real
SFTP cifrado · Datos embebidos en imágenes · Cloud storage
TA0040
Impacto
El objetivo final del atacante: cifrar datos, destruir sistemas, interrumpir servicios.
Ejemplo real
Ransomware · Wiper malware · DDoS

Cómo RMSecurity aplica MITRE ATT&CK

Cuando el programa procesa una noticia de ciberseguridad, ejecuta una clasificación automática en varias etapas:

1

Descarga y limpieza del artículo completo

El programa no se queda con el resumen del RSS (~150 palabras). Descarga el artículo completo con BeautifulSoup, elimina navegación, headers y scripts, y extrae el texto del cuerpo. Esto permite encontrar IoC que nunca aparecen en el resumen.

2

Detección de táctica MITRE

El texto completo se compara contra un diccionario de más de 120 palabras clave mapeadas a tácticas ATT&CK. El sistema usa coincidencia de múltiples términos para resolver ambigüedades — "ransomware" activa TA0040 (Impact), pero "initial access" + "phishing" activan TA0001.

3

Clasificación de categoría y severidad

Se asigna categoría (RANSOMWARE, APT/ESPIONAJE, VULNERABILIDADES, etc.) y severidad (CRÍTICO/ALTO/MEDIO/BAJO). Si se detecta un CVSS ≥ 9.0 en el texto, la severidad se eleva automáticamente a CRÍTICO independientemente de la categoría.

4

Extracción de IoC

Con el texto completo disponible, el sistema extrae mediante expresiones regulares: CVEs, IPs (excluyendo rangos privados), hashes MD5/SHA256, grupos APT, víctimas, países, montos de rescate, wallets crypto y técnicas T1xxx.

5

Inferencia de atribución

Si se detecta un grupo APT (ej: Lazarus Group), el sistema infiere automáticamente el país de origen usando un mapa de más de 50 grupos con su atribución conocida.

Por qué ATT&CK cambia el juego defensivo

El valor real de MITRE ATT&CK no es solo clasificar ataques — es que te permite pensar como el atacante y anticiparte. Si sabés que un grupo APT usa phishing como acceso inicial (TA0001) y luego siempre pasa por escalada de privilegios (TA0004), podés reforzar esas capas específicas antes de que lleguen al ransomware.

En el contexto de una organización, cada noticia procesada por RMSecurity responde cuatro preguntas clave:

¿Quién ataca?
Grupo APT, país de origen, historial de campañas similares.
¿Cómo ataca?
Táctica MITRE, técnicas T1xxx, vector de entrada inicial.
¿A quién afecta?
Sector víctima, país, software afectado, versiones vulnerables.
¿Qué busca?
Datos robados, rescate exigido, impacto reportado, sistemas afectados.
